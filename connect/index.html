접속 방법

소속 기관 계정으로 접속합니다. 방문한 기관에서 계정을 따로 받을 필요가 없습니다.

소속 기관 안내 페이지를 먼저 확인하세요. realm, 인증서 값, 이용 가능한 장소는 기관마다 다릅니다. 기관 목록에서 찾아보기

접속 정보

네트워크 이름(SSID)eduroam
보안WPA2/WPA3 엔터프라이즈
EAP 방식PEAP 또는 TTLS (기관마다 다름)
아이디아이디@소속기관도메인 — 예: hong@example.ac.kr
비밀번호소속 기관 Wi-Fi 비밀번호
익명 아이디anonymous@소속기관도메인 (입력란이 있을 때만)

아이디에서 @소속기관도메인을 빼면 접속되지 않습니다. 인증 요청을 어느 기관으로 보낼지 정하는 값입니다.

  • 국내 기관의 소속기관도메인은 .kr 로 끝납니다.
  • 학교 메일 주소와 같을 수도 있고 다를 수도 있습니다. 메일 주소라고 생각하고 넣으면 틀릴 수 있습니다.
  • 정확한 값은 소속 기관 eduroam 안내 페이지에서 확인하세요.

CA 인증서 설치

CA 인증서를 설치하지 않거나 인증서 지문을 확인하지 않고 접속하지 마십시오. 확인을 건너뛰면 eduroam이라는 같은 이름으로 위장한 가짜 접속점에 연결될 수 있고 그 경우 입력한 아이디와 비밀번호가 공격자에게 그대로 넘어갑니다.

인증서 파일과 지문 값은 소속 기관이 공개합니다. 방문한 기관 것이 아니라 소속 기관 것을 사용하세요.

OS별 설정 방법

Windows
  1. 소속 기관 CA 인증서를 내려받아 두 번 누릅니다. 인증서 설치 → 저장소 위치 현재 사용자 → 모든 인증서를 다음 저장소에 저장 → 신뢰할 수 있는 루트 인증 기관.
  2. Wi-Fi 목록에서 eduroam을 선택합니다.
  3. 아이디@소속기관도메인과 비밀번호를 입력합니다.
  4. 인증서 확인 창에서 인증서 세부 정보 표시를 눌러, 인증서 이름과 지문이 기관이 공개한 값과 같은지 확인한 뒤 연결합니다. Windows 연결 창은 SHA-1 을 보여줍니다.
macOS · iOS · iPadOS
  1. macOS: CA 인증서를 내려받아 두 번 누르면 키체인 접근의 로그인 키체인에 들어갑니다. 다시 두 번 눌러 신뢰를 펼치고 이 인증서 사용 시를 항상 신뢰로 바꿉니다.
  2. iOS·iPadOS: Safari 로 내려받은 뒤 설정 → 일반 → VPN 및 기기 관리에서 프로파일을 설치하고 이어서 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 켭니다. 이 마지막 단계를 빠뜨리면 신뢰되지 않습니다.
  3. Wi-Fi 목록에서 eduroam을 선택하고 계정을 입력합니다.
  4. 인증서 화면에서 이름과 지문을 확인한 뒤 신뢰를 누릅니다. macOS·iOS 는 SHA-256 을 보여줍니다.
Android
  1. CA 인증서를 내려받아 설정 → 보안 → 암호화 및 자격 증명 → 인증서 설치 → CA 인증서에서 설치합니다. 메뉴 이름은 제조사와 버전에 따라 다릅니다.
  2. Wi-Fi 목록에서 eduroam을 고릅니다.
  3. EAP 방식과 2단계 인증은 기관 안내대로 선택하고 CA 인증서는 방금 설치한 것을 지정합니다. 도메인 칸에는 기관이 안내한 서버 이름을 넣습니다.
  4. 계정을 입력하고 연결합니다. 인증 안 함이나 확인하지 않음은 선택하지 마세요.

보안 정책

  • 계정은 본인만 사용해야 하며 타인에게 양도하거나 공유할 수 없습니다.
  • eduroam 은 인증 처리를 위해 접속 기록을 남깁니다. 기록은 소속 기관과 방문 기관 양쪽에 보관되며 장애 처리와 보안 사고 대응 목적으로만 이용합니다.
  • 기관에 따라 포트 차단이나 대역폭 제한이 있습니다. 방문한 기관의 정책을 따라야 합니다.
  • 저작권 침해, 무단 침입, 악성코드 유포 등 관계 법령을 위반하는 행위가 확인되면 사전 통보 없이 접속을 차단하고 소속 기관에 통보합니다.
