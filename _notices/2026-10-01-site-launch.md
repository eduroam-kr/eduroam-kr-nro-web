title_en: "eduroam Korea site refresh"
date: 2026-10-01

대한민국 에듀롬(eduroam) 공식 웹사이트를 개편하였습니다.

* 국내 에듀롬 참여기관 정보가 많이 누락되어 현행화 하였습니다.
* 에듀롬 활용에 유용한 정보를 전달하도록 구성하였습니다. OS별 설정 방법을 자세히 안내하였고, `CA 인증서 설치 및 확인`을 강조하였습니다.

대한민국 에듀롬(eduroam) 공식 GitHub [github.com/eduroam-kr](https://github.com/eduroam-kr) 을 운영합니다.

* 참여기관 정보는 [eduroam-kr-db](https://github.com/eduroam-kr/eduroam-kr-db) 레포로 관리됩니다.
    - 참여기관 정보에 잘못된 것이 있으면 Pull Request 하여 수정할 수 있습니다.
    - 본 정보는 [글로벌 에듀롬 서비스 지도](https://monitor.eduroam.org/map_service_loc.php)와도 연동되도록 하였습니다.
* 대한민국 에듀롬(eduroam) 공식 웹사이트 - [eduroam.kreonet.net](https://eduroam.kreonet.net) 가 서버 없이 GitHub Pages 로 호스팅 됩니다.
* 참여기관 에듀롬 서비스 안내 템플릿 [onepage-html-site-theme](https://github.com/eduroam-kr/onepage-html-site-theme) 및 유용한 정보를 제공합니다.
